# B站动态带货折叠

Tampermonkey正式脚本分发仓库，当前版本：**1.4.4**。

## 安装与更新

1. 在浏览器中安装并启用Tampermonkey。
2. 点击[安装正式脚本](https://raw.githubusercontent.com/areusa/bilibili-ad-fold-release/main/bilibili-ad-fold.user.js)，确认安装；已安装时也可用[脚本全文](./bilibili-ad-fold.user.js)覆盖原脚本并保存。
3. 刷新B站动态页、视频页或稍后再看播放页。

脚本内的更新和下载地址均指向本仓库的固定Raw地址。已从旧地址安装的用户，需要先完整覆盖一次脚本；若在油猴设置中手工填写过“更新URL”，也要改为上面的安装地址，或恢复使用脚本元数据。保留脚本名称和namespace，无需卸载，可沿用已有设置。

后续由Tampermonkey按用户设置检查更新；远端版本必须高于已安装版本。Raw地址无法访问时，本地已安装脚本仍可运行。

## 功能

- 折叠疑似带货动态，支持手动展开、自定义关键词、UP汇总及动态位置轨道。展开只改变显示状态，不撤销广告判定。
- 从视频简介和首条主评论识别推广线索，在播放器左上角提示；提示会在5秒后收起，可关闭或再次展开。
- 结合社区标注及可用字幕规则，在原生进度条标记疑似推广区间；标记不可选中、光标穿透，不改变原生拖动。

关键词设置入口位于动态页左下角面板；视频相关开关及状态位于本脚本的油猴菜单。

广告记录面板支持点击外部区域收起；面板内编辑、轨道定位继续正常使用。再次点击“广告记录”或按Esc也可收起，收起保留未保存的关键词输入。

## 兼容与边界

面向Chromium内核浏览器与Tampermonkey，已在Chrome 155及Tampermonkey 5.5.1实装验证；Chromium 122尚未实装验证。

规则和社区标注可能误判或漏判。无字幕、接口失败或未命中均不代表视频没有推广，也不保证打开后5秒内一定得出区间。当前不含音频转写和OCR，不调用大模型API，不需要本地服务。

## 网络与设置

关键词及放行设置保存在Tampermonkey本地存储中。脚本可向B站视频、评论及字幕接口请求数据，并向`bsbsb.top`查询社区区间；社区查询默认开启，发送视频编号的哈希前缀、查询类别、脚本版本及必要网络信息，可在油猴菜单关闭。脚本不提取或导出Cookie，不上传自定义关键词或动态正文，不访问商品链接。字幕元信息请求正常使用B站登录会话；页面自身的评论加载也遵循站点登录状态。评论预检、社区查询及字幕正文请求为匿名请求。

评论预检有请求预算、间隔、取消及冷却；网络或风控失败后退回已有页面内容，不无限重试。源码及第三方内容说明见[正式脚本](./bilibili-ad-fold.user.js)和[第三方声明](./THIRD_PARTY_NOTICES.md)。
